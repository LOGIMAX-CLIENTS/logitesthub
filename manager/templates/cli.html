{% set agent_md %}## UI testing with LogiTestHub (Tester CLI) - After changing UI code, verify it with `tester`. Always add `--json`; read `status`, `url` and `report` from the output. - Never write login steps: the project's login helper runs first (pass `--var username=... --secret password=...`). Testing the login page itself: `login: none` in the case front matter. - Write tests as short plain-English steps, one per sentence: Navigate to … / Type … into the … field / Select '…' from the … dropdown / Click the … button / Assert the text '…' is visible. - Run: `tester run "" --url --project --json` - Saved case: `tester run --case --url --json` (find ids with `tester cases --json`). - New cases for a change: `tester generate "" --project --diff --json`, then ask the user to review them. - Exit codes: 0 passed, 1 failed, 3 partial (some steps need AI), 4 AI limit reached (stop and tell the user), 2 other error. - Pass passwords only with `--secret name=value`; never print the access key or secrets. - Before writing or running a test: `tester lessons --json` and follow every lesson. - On failure, open the `url` / `report`, find why (app bug, test out of date, environment, test data, how we test), fix it, run again until it passes, then record it: `tester lesson add --project --kind --title "" --avoid "" --json`.{% endset %}
