How to connect

  1. Get the PM MCP URL and key from the PM team (the key privately, not in a group chat).
  2. Paste them, then Test connection: it lists the tools the key may call. {% for t in need %}{{ t }}{{ ' and ' if not loop.last }}{% endfor %} must be there.
  3. Set the LogiTestHub address to one PM users can open, then Save.
  4. Fill each tester's email in Users exactly as in PM, and switch on Pick up Tester CLI clicks on one server.
  5. On a PM task, click Tester CLI: the task's page here shows the click and whether each run's link was attached.
